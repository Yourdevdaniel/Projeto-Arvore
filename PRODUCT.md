# Product

## Register

product

## Users

Alunos de Estruturas de Dados usando o navegador para entender estruturas passo a passo, sem depender de terminal Python local.

## Product Purpose

Visualizar codigo Python didatico linha por linha, mostrando o estado da estrutura de dados, a linha atual, a saida e erros recuperaveis. Sucesso significa o aluno conseguir copiar, ajustar e observar o proprio codigo sem travar a pagina.

## Brand Personality

Didatico, direto, academico. A interface deve parecer uma ferramenta de laboratorio de aula: clara, confiavel e sem enfeite comercial.

## Anti-references

Nao deve parecer landing page, dashboard corporativo, editor profissional complexo ou simulador cheio de decoracao. Evitar efeitos que atrapalhem leitura do codigo ou o acompanhamento passo a passo.

## Design Principles

- Mostrar o estado da estrutura antes de explicar.
- Reaproveitar o mesmo fluxo para cada estrutura estudada.
- Priorizar codigo, execucao e visualizacao na primeira tela.
- Falhar com mensagem clara, nunca com pagina quebrada.
- Manter comandos simples para aluno iniciante.

## Accessibility & Inclusion

Manter contraste forte, layout responsivo, suporte a movimento reduzido e controles acessiveis por teclado quando fizer sentido para o fluxo passo a passo.
